OSWM accessible routing

This experimental router uses mapped OpenStreetMap accessibility information and estimated terrain slope.

  1. Select a routing profile.
  2. Optionally compare an accessibility profile with the distance-only route.
  3. Click a route origin.
  4. Click a destination.
  5. A third click starts a new route.

Missing data can affect the result. Profile grades are provisional and are not a guarantee that a route is accessible.
